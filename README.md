# Paws of Cape Town

Marketplace for Cape Town rescue shelters to list animals and manage adoption enquiries.

## Local Development

Start Postgres:

```bash
npm run db:up
```

Run database migrations:

```bash
npm run db:migrate
```

Start the app:

```bash
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run lint
npm run build
```
